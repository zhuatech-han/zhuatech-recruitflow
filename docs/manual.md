# 招聘协作操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2

## 开始招聘

管理员登录“账号与设置”，先确认部门，再添加招聘人员、招聘负责人、面试官。为每人设置独立强密码，不共用管理员账号。角色为部门范围或本人任务范围。内建权限与菜单只允许改显示名称与可见配置，不能凭菜单创建业务能力。

招聘人员新建岗位：填写地点、全职/兼职/合同制、人数、职责与要求，指定同部门的招聘人员和不同账号的审批负责人。草稿可改可删；送审后退回可继续修改，但有流程历史不再允许物理删除。负责人批准后开始招聘，岗位业务归属、描述与人数冻结，避免申请记录对应的岗位被改写。

“暂停投递”停止公开投递，已有申请继续处理，招聘人员仍可人工登记；恢复后重新公开。负责人只能在所有申请均入职、拒绝或撤回后关闭岗位。负责人可以交接岗位招聘人员；每份在途申请的招聘人员另行交接。

## 在线投递

管理员在参数设置中填写companyName、privacyNotice（至少50字符）与privacyContact，再将publicIntake设为true。说明由资料处理的实际部署方提供，包含真实用途、处理方式、保留安排和联系入口。没有公开默认声明替代部署方责任。公开页面路径 `/careers`，只展示已批准且招聘中的岗位。

候选人填写姓名、联系邮箱、经历与意向，电话和PDF简历可选，阅读说明后勾选确认。接口保留当前说明摘要和确认时间。同岗位同邮箱重复投递只返回统一收到消息，不覆盖原资料，不泄漏是否已有申请。没有候选人登录和进度查询。每会话每分钟最多5次、单进程所有公开投递每分钟最多100次；这不是身份验证或抗大规模攻击方案。

## 招聘推进

人工录入必须记录资料合法取得或授权凭据，来源为字典中启用项。NEW与SCREENING阶段可修改基本资料和当前PDF；开始面试后冻结资料。无历史且非在线申请的人工记录可删除，其余使用流程结束或资料处置。

初筛后安排面试：选择同部门面试官，输入时间和地点/会议链接。时区按浏览器本地显示，提交与数据库存UTC。最长4小时，最多回溯30分钟记录已安排面试；最多366天后的预约。最多20条面试记录。相邻时段不冲突，重叠的非取消记录被拒绝，取消预约释放该时段。

只有指定面试官可在结束时刻后录入人工建议和反馈。已经完成反馈不可改写，有误用跟进备注解释并重新安排必要的复核面试。其他面试官看不到这份申请，普通面试官不返回内部备注、他人的反馈和薪资。简历下载再次检查申请范围。

## 录用与入职

至少有一次出席面试的完成反馈且没有待面试预约，招聘人员才可新建录用建议。NO_SHOW不算出席。填写正数金额、月薪/年薪、约定入职日期、有效期和条款。草稿可改可删，送审后由岗位负责人独立审核，创建人不能审核自己的录用建议。

批准占用名额；已批准、已送达、已接受建议都占用名额，实际入职后仍计已使用名额。不同申请同时审批也不能突破岗位人数。拒绝、撤销、候选人婉拒、撤回或执行到期释放会释放未入职建议名额。有效期不会自动执行；到期后点击“释放过期建议”。已接受建议不自动到期，可以登记入职或负责人撤销。

送达和接受必须填写外部实际凭据，例如内部邮件记录号；系统只保存记录，不发送邮件、不签署合同。不得将自己的草稿当作已送达录用通知。已接受后由负责人填写实际入职日期与唯一员工编号，日期不得早于约定日期、不得晚于当前UTC日期。

## 统计与资料处置

统计页显示权限范围内岗位八阶段计数，CSV不含候选人个人资料。历史和审计用于追溯操作者与状态，没有编辑入口。

只有具备privacy权限的人员能将已结束申请匿名化；此操作不可恢复，需遵循部署方实际资料处置要求。它移除当前库的个人文本、薪资、简历和凭据，但保留岗位、状态、时间与操作者等非个人内容。备份、外部邮件和已下载文件需单独管理；不是自动保留期限处理或合规认证。上线前确认数据库和备份访问控制。
